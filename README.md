# PFIN Services React Website

Responsive React/Vite demo website with component-based navigation and pages, animated process flow cards, mobile navigation, contact form demo, and crest on Our Ethos.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open terminal in the project folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the localhost address Vite prints (usually http://localhost:5173).

## Components / pages
- `src/components/Navbar.jsx` – responsive menu
- `src/components/Footer.jsx` – legal/contact footer
- `src/components/Flowchart.jsx` – animated horizontal process nodes
- `src/pages/Home.jsx` – homepage
- `src/pages/ServicePages.jsx` – Advisory, Briefings, Vault
- `src/pages/Contact.jsx` – demo inquiry form
- `src/pages/Ethos.jsx` – full crest and legacy statement
- `public/crest.png` – supplied crest

## Important
This is a frontend demonstration. The contact form only shows a local success state. Subscription payments, member login, booking, email delivery, diagnostic workflows, and automated account provisioning require backend/provider integrations. Confirm DBA/entity disclosures before publishing.
